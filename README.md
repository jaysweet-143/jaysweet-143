## 🚀 Recent Work

| Project | What it does | Highlights |
| :-- | :-- | :-- |
| Power-of-Two Max Heap - 'walmart-advanced-software-engineering-job-simulation' (`PowerOfTwoMaxHeap.java`) | Implements a high-throughput, array-backed d-ary priority queue where every parent node has \(2^{x}\) children, designed to eliminate ingestion bottlenecks in high-volume shipping and event-streaming systems. It dynamically configures the tree's branching factor at instantiation and manages priority ordering through contiguous index arithmetic (insert and popMax) without object pointer overhead. | Engineered single-cycle bitwise left-shifting (1 << branchingPower) and long intermediate casting to prevent 32-bit integer overflow when benchmarking extreme branching exponents. Built defensive boundary checks to handle empty heap states, single-element removals, and partial child blocks without off-by-one errors. Learnt how flattening tree depth accelerates high-frequency write operations at the trade-off of wider scan loops during maximum extraction. |
| **'XX' Global Telemetry Engine - 'XX_telemetry'** (`ingest_shield.py`, `telemetry_bench.py`, `metrics_manifest.txt`)| Processes continuous, high-volume event streams using defensive data governance filters modeled after Google Site Reliability Engineering patterns. It automatically repairs missing regional parameters with unassigned-edge tracking flags and routes corrupted records into an isolated Dead Letter Queue without halting ingestion. | Engineered a live latency monitor that tracks system response times and flags service level agreement breaches when performance slows past 100ms. Implemented an automated file-writing layer that outputs a metrics manifest log detailing total events processed and system health status. Learnt that  real-world pipelines require automated alerting monitors so data transformations can run completely unattended without dropping tracking records. |
| **Inbound File Router** (`data_router.py`) | Checks incoming data batches and runs structural validation before ingestion | Safe key lookups with `.get()` so missing fields no longer crash the run |
| **Mobile Money Validation Shield** (`momo_shield.py`) | Validates mixed-provider transaction batches and applies a 5% fee calculation before staging | Dead Letter Queue pattern isolates bad records without stopping the pipeline |
| **Search Optimisation Models** (`search_models.py`) | Binary search over large sorted datasets using low and high index pointers | Logarithmic lookups, with an operator precedence bug found and fixed |
